# QA — Шахта импульсов 0.1
25.10.2026. Статус: локальный MVP, не опубликован и не проверен в черновике Яндекс Игр.

## Проверено
- Node 24.21, TypeScript 5.9, Vite 7.3.7, Phaser 3.90, Playwright Chromium 1.64.1.
- npm test: 15/15 на момент отчёта; правила зарядов, cooldown, TNT, последовательность покупок, однократные награды, поражение без списания, проходимость всех 12 карт, восстановление снимка, паузы и рекламные callbacks.
- npm run build: проходит. Production около 1.27 МБ без сжатия.
- Browser desktop 1440×1000: первый спуск → победа → +63 наггета; второй → суммарно 168 → покупка каменной за 100 → баланс 68, кирка stone.
- Следующий уровень с каменной: первый толчок расходует заряд, второй его не возвращает. HUD отражает текущую прочность и глубину.
- Пауза: физическое время не меняется. Перезагрузка активного спуска предлагает продолжить контрольное состояние.
- Mobile viewport 390×844: кнопка запуска в пределах экрана, горизонтального скролла нет, 368px canvas.
- Запуск при localStorage SecurityError: экран игры доступен, ошибка сохранения обрабатывается.
- JavaScript pageerror в проверенных браузерных потоках: 0.
- Свежий независимый code review: 2 Important найдено и исправлено; Critical/Minor нет.
  1. Облачные записи блокируются до выбора конфликтующего сохранения. Регрессионный тест: облачный кошелёк 900 не затирается локальными 20.
  2. Убрано незащищённое чтение localStorage из boot. Регрессионный тест и browser SecurityError-проверка проходят.
- Исправлен HUD после нового спуска: счётчики обновления сбрасываются при уменьшении времени новой попытки.

## Не подтверждено
- Реальные Yandex SDK/cloud/rewarded/interstitial: нужен черновик в Консоли и подключённая монетизация.
- Safari/iOS и физический бюджетный Android: проверены размеры окна, а не реальные устройства.
- Возрастная маркировка, финальное название и промоматериалы не заполнены.
- Удержание, экономика, сложность и длительность требуют пользовательского плейтеста. Числа ресерча не используются как доказанные метрики.

## Решения реализации
- Новый проект в отдельной папке без Git-репозитория. Исходники передаются архивом; ветки/коммиты/публикация не создаются.
- Кастомная фиксированная симуляция с круговым коллайдером; Phaser отвечает за отрисовку. Вращение визуальное, физика не повторяет точную форму кирки.
- Карты — детерминированные авторские рецепты, без бесконечного генератора.
- Частота рекламы внутренняя, около 2 минут между попытками; не норматив платформы.
- Standalone HTML собирается из preview-режима без SDK и без имитации рекламных наград.
