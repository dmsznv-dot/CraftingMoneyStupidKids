# Шахта импульсов — MVP 0.1
Браузерная 2D-игра с автоматическим спуском кирки, разрушаемыми блоками и постоянной прокачкой.

## Текущий объём — только MVP
Пользователь откладывает проверку SDK в черновике Яндекс Игр, реальные устройства, финальную настройку баланса и публикацию. Они не блокируют передачу этого прототипа.

## Продолжение разработки
Список сделанного и приоритеты доработок: [HANDOFF.md](HANDOFF.md). Согласованные правила: [GAME_SPEC](docs/GAME_SPEC.md). Реальные проверки: [QA.md](QA.md).

## Играть
Для запуска из репозитория: npm ci, затем npm run dev. Для автономного HTML: npm run package → artifacts/MINING_GAME_PLAY.html.

Откройте отдельный файл MINING_GAME_PLAY.html в браузере. Установка, аккаунт и сервер не требуются. Это локальный предпросмотр: рекламы нет, бонус за несуществующий просмотр не выдаётся. Прогресс хранится в браузере на этом устройстве. В приватном режиме/при запрете хранилища сохранение может быть недоступно; игра сообщает об этом.

В игре выберите точку сброса в верхней части шахты и нажмите «Сбросить кирку». Кирка падает и вращается сама.
Каменная кирка даёт одно подталкивание, железная — два, золотая — три, алмазная — четыре. Используйте кнопки под полем или стрелки клавиатуры. Удержание не расходует заряды повторно.
Победа — добраться до нижнего выхода с оставшейся прочностью. Наггеты за победы тратятся в мастерской. Неудача не списывает кошелёк.
Стартовый TNT даёт один размещаемый заряд на каждую попытку. Зачарования постоянные, активен один эффект.
Звук включается после действия игрока, отключается верхней кнопкой. Пауза — кнопка в шахте или Escape.
12 шахт, 5 кирок, 2 зачарования, RU/EN. Первый спуск около 20 секунд, дальнейшие 25–50 секунд в текущем балансе. Это ранний баланс, не финальная длительность.

## Работа с исходниками
Требуется Node 22.18+ (проверено Node 24.21) и npm.
```sh
npm ci
npm run dev
npm test
npm run build
```
Dev-адрес по умолчанию — http://127.0.0.1:5173. Production в dist, локальная сборка без SDK: npm run build:preview.

## Яндекс Игры
Архив MINING_GAME_YANDEX.zip содержит production-сборку, index.html в корне.
SDK динамически подключается из /sdk.js; production использует реальные методы SDK. Dev и preview не выдают себя за реальный SDK.
LoadingAPI, GameplayAPI, platform pause/resume, cloud + local save, выбор конфликтующих сохранений, interstitial на результате и добровольное удвоение награды реализованы в адаптере.
Без SDK игра остаётся доступной локально, реальных рекламных показов и cloud при этом нет.
Первый interstitial не раньше двух минут активной игры; дальнейшие попытки не чаще двух минут и только по кнопке нового захода. Это внутренняя политика, не норматив Яндекса.
Sticky не включать: место нужно шахте и управлению. TV и покупки не заявлять.
В Консоли: desktop + mobile portrait, RU/EN, cloud save, interstitial + rewarded; настройте монетизацию своего аккаунта. Возрастная маркировка/название/промоматериалы требуют отдельного заполнения.
Реальный SDK, облако, реклама и iOS/Android на физических устройствах ещё не проверены. Архив — кандидат для черновика и проверки, не подтверждённая модерацией игра.
Нет публикации, игровых покупок за реальные деньги и внешних рекламных сетей.

## Устройство кода
- src/core.ts — физика, фиксированные карты, разрушение, TNT и импульсы.
- src/progress.ts — экономика, постоянные покупки, однократные награды.
- src/scene.ts — Phaser-рендеринг, собственные пиксельные текстуры и эффекты.
- src/main.ts — DOM-интерфейс, переходы, игровой цикл.
- src/platform.ts — SDK, рекламные callbacks, причины паузы.
- src/storage.ts — проверка схемы, локальное сохранение, cloud-очередь.
- tests — тесты правил, проходимости, сохранений и рекламных веток.

## Ограничения
Сейв на клиенте не защищён от изменения пользователем. Нет сервера, поддержки смены аккаунта в интерфейсе, таблиц лидеров и процедурных бесконечных уровней.
При ошибке чтения cloud записи туда блокируются до следующего запуска, чтобы не затереть неизвестный прогресс.
Критические сохранения отправляются немедленно; периодические снимки — с ограничением частоты. Одновременные cloud-записи сериализованы.
Изображения, звук и текстуры созданы в коде; ресурсы Minecraft и видео референса в билд не входят.
