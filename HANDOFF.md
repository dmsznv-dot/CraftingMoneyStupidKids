# Передача проекта следующему разработчику
Дата: 25.10.2026. Статус: рабочий локальный MVP. Текущий объём ограничен проверкой игрового цикла; публикация не входит в задачу.

## Начать здесь
1. Прочитать AGENTS.md и docs/GAME_SPEC.md — согласованные правила.
2. Выполнить npm ci, npm test, npm run build.
3. Запустить npm run dev. В чистом профиле пройти две шахты, купить каменную кирку, проверить единственный толчок.
4. Прочитать QA.md: это фактически выполненные проверки, а не обещания.
5. Работать в своей ветке. Не изменять утверждённый игровой цикл без отдельной задачи.

## Что уже сделано
- TypeScript + Vite + Phaser 3, отдельная от движка фиксированная симуляция.
- Автоматическое падение/вращение, разрушаемые земля/камень/плотная порода/руда.
- 12 фиксированных карт, выход внизу, победа/поражение по прочности.
- Пять кирок: деревянная 0, каменная 1, железная 2, золотая 3, алмазная 4 подталкивания.
- Общий запас на оба направления, cooldown, без автоповтора клавиши, восстановление на каждом заходе.
- TNT с цепными взрывами, постоянный стартовый TNT с выбором клетки.
- Наггеты только после победы; фиксированная награда + руда; повтор бесплатный, поражение не списывает кошелёк.
- Последовательные покупки кирок, один активный слот, «Ударная волна» и «Рудная цепь».
- Подготовка, мастерская, выбор шахты, результат, пауза; RU/EN; собственные текстуры/звуки.
- Локальные снимки спуска, валидация сохранений, облачная очередь SDK, явный выбор конфликтующих сейвов.
- SDK adapter: динамический /sdk.js, язык, Ready/Gameplay, pause/resume, interstitial и rewarded.
- Отдельный preview без SDK и без фиктивной выдачи рекламной награды.
- 15 тестов и отдельный браузерный smoke. Независимое code review, две найденные Important-проблемы исправлены.

## Отложено по решению пользователя — после MVP
SDK в черновике, реальные устройства, финальный баланс и подготовка к публикации сейчас не блокируют MVP. Следующие пункты сохраняются как справочник для будущего релиза.
### 1. Реальная платформа
Создать/выбрать черновик Яндекс Игр и загрузить production ZIP. Сейчас у проекта нет APP_ID и нет проверки Консоли.
Проверить реальную загрузку SDK, язык, Game Ready, Gameplay, начальную платформенную рекламу.
Проверить cloud у гостя/вошедшего пользователя, reload, потерю сети и конфликт устройств.
Подключить monetization interstitial/rewarded в Консоли. Sticky оставить выключенным, покупки и TV не заявлять.
Проверить onRewarded/onClose/onError, отсутствие ролика, повторный клик, hidden при close, пользовательскую паузу до ролика. Не выдавать локальную симуляцию за реальную интеграцию.

### 2. Загрузка и ошибки SDK
В src/platform.ts есть таймаут загрузки скрипта /sdk.js, но нет ограниченного ожидания для YaGames.init()/getPlayer(), а в SaveStore.load() — getData().
Добавить безопасные пределы ожидания/повтор и проверить сценарий, когда Promise не завершается. Не запускать позднюю запись, пока неизвестно сохранение пользователя, и не заменять облако новым пустым прогрессом.
При закрытии страницы до обработки рекламного callback абсолютная гарантия выдачи невозможна на одном клиенте — не обещать её.
Если Cloud setData/локальная запись не проходят, проверить восстановление подтверждённого бонуса без требования повторного просмотра.

### 3. Реальные устройства и lifecycle
Проверить Chrome/Android на бюджетном телефоне, Safari/iOS, desktop.
390×844 уже проверено как viewport, но это НЕ тест на физическом устройстве.
Проверить портретную ориентацию в Консоли, поворот без reset, safe-area, fullscreen, background/focus, звук после блокировки устройства.
Проверить устойчивые 30 FPS, длинную сессию, несколько TNT одновременно, WebGL context loss.

### 4. Контент и модерация
Сверить актуальные требования Яндекс Игр; рабочий стандарт пользователя не заменяет текущую документацию.
Проверить уникальность финального названия в каталоге и сравнить ближайшие игры по механике/контенту/UI/дизайну.
Подготовить возрастную маркировку, локализованные описания/инструкции, иконку, обложки и реальные скриншоты/видео.
Ресурсы Minecraft не использовать. Название репозитория — внутреннее, оно не является названием игры/описанием аудитории на витрине.

## Возможные доработки MVP — после первого фидбэка
Сейчас не требуется доводить баланс до финального. Сначала дать пользователю поиграть в готовый цикл.
- Провести ручной плейтест всех 12 шахт. Автотест доказывает существование маршрута деревянной киркой, а не понятность/интерес каждого уровня.
- Начальный баланс даёт около 20 секунд на первом уровне и 25–50 на следующих, вместо исходной гипотезы 45–90. Не растягивать механически: сначала измерить, хочется ли повторять.
- Проверить, заметен ли эффект каждого инструмента, зачарования и стартового TNT, нет ли единственной очевидно лучшей покупки.
- Проверить, что отклонение к руде выгодно, а подталкивание слабое и ощущается точечным вмешательством.
- Доработать коллизию, если круговой коллайдер слишком расходится с видимой киркой. Сейчас вращение визуальное.
- Добавить контекстное обучение первому толчку: текущий интерфейс содержит подсказку, но нет отдельного специально поставленного учебного эпизода.
- Доработать идентичность блоков/кирки/звуков и обратную связь крупных цепей. Физического обрушения отдельных блоков пока нет.
- Проверить склонение «импульс/импульса/импульсов» и локализацию ошибок запуска; это полиш текстов.

## P2 — после проверки ядра
Дополнительные задания, рекорды по добыче, аналитика событий и эксперименты баланса.
Бесконечная генерация, live multiplayer, сервер, платежи, leaderboard не входят в текущую задачу.
Не добавлять случайные покупки, ставки, потерю кошелька и рекламные подталкивания: пользователь их не утверждает.

## Воспроизводимые команды
```sh
npm ci
npm test
npm run build
npm run dev
# В отдельном терминале, пока dev-сервер работает:
npm run test:browser
# Для отдельных файлов:
npm run build:preview
npm run package
```
Для browser smoke нужен Chromium: npm exec playwright install chromium.
После package:
- artifacts/MINING_GAME_PLAY.html — автономный предпросмотр, открыть в браузере.
- artifacts/MINING_GAME_YANDEX.zip — production, загрузить в черновик и проверить.
- artifacts/MINING_GAME_SOURCE.zip — исходники, тесты и документация.

## Критерий готовности текущего MVP
Игра запускается локально; автоматический спуск, разрушение, TNT, награда, магазин и ограниченные подталкивания составляют рабочий цикл; тесты и сборка проходят. Эти проверки выполнены.
Проверки SDK/cloud/рекламы на платформе, физических устройств, финальный баланс и модерация отложены пользователем. Не выполнять их без следующей задачи.
